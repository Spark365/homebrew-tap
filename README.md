# Spark 365 Homebrew Tap

Official Homebrew tap for apps by [Spark 365 Ltd](https://deskstag.com).

## Install DeskStag

```sh
brew tap spark365/tap
brew install --cask deskstag
```

[DeskStag](https://deskstag.com) names and colour-codes your desktops, right inside Mission Control. The cask installs the notarised build served from deskstag.com; the app keeps itself up to date.
